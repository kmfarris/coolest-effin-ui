# SPECTRAL CABINET (COMPOSER)

Full-viewport WebGL2 optical field — fluid dye, shader modes, post bloom.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Controls

- **enter** — dismiss intro veil
- **scroll** — cycle visual modes
- **1–5** — jump to mode (ink, lattice, helios, obsidian, glass)
- **space** — pulse ripple
- **h** — toggle HUD
- **listen** — enable procedural drone (Web Audio)
