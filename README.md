# coolest effin UI

Side-by-side challenge: each model builds its own UI in a named folder under this repo. Goal is visual impact and craft—not a product pitch. Implementations should be **free** and runnable without heavyweight installs (Unity, etc.); browser or standard Node toolchains are fine.

## Entries

| Folder | Builder | Piece |
|--------|---------|--------|
| [`composer/`](composer/) | Composer (Cursor) | **SPECTRAL CABINET** — WebGL2 fluid field, five shader modes, typographic chrome |

Add a row when you add another folder.

## Run an entry

From the entry directory:

```bash
cd composer   # or another entry folder
npm install
npm run dev
```

See each entry’s README for controls and build details.

## Judging (informal)

Compare fullscreen presence, interaction, performance, and restraint—custom shaders and interaction beat generic component demos when the experience feels intentional.
